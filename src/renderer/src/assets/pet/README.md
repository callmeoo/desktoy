# 小道童立绘 / Pet artwork

把你的真实立绘放进**这个文件夹**，程序会自动用它替换代码里的占位 SVG。

## 命名规则（文件名 = 状态名）

| 文件名 | 对应状态 | 设计稿参考 |
| --- | --- | --- |
| `idle.png` | 待机（也是默认兜底） | 待机打坐 |
| `meditate.png` | 入定打坐 | 待机打坐 / 专注陪伴 |
| `happy.png` | 开心 | 开心转圈 |
| `focus.png` | 专注 | 专注陪伴工作 |
| `tired.png` | 困倦 | 困倦打哈欠 |
| `worried.png` | 担心 / 安慰 | 心情不好时安慰用户 |

- 支持 `.png` `.gif` `.webp` `.jpg`（动图用 `.gif`）。
- **建议透明背景的 PNG**，这样悬浮在桌面上才不会有白底方块。
- 只放 `idle.png` 也行：其它状态会自动回退到它；完全不放则用占位 SVG。
- 改完图片后重新运行 `npm run dev` 即可看到效果。

## 怎么得到透明背景的 PNG（任选其一）

- **网页**：把单张立绘传到 remove.bg，下载抠好的透明 PNG。
- **macOS 自带**：在「访达」里选中图片 → 右键 →「快速操作 / 拷贝主体」，
  或用「预览」框选主体后删除背景，导出为 PNG。
- 设计软件（Photoshop / Pixelmator / Figma）直接导出透明 PNG。
